# Security Policy

This repository currently documents a project concept rather than a runnable application. If executable code is added, security fixes will be considered for the latest version on the default branch.

Do not disclose suspected vulnerabilities or secrets in a public issue. Use this repository's **Security** tab and **Report a vulnerability** option where available, or contact the repository owner through the [InnovatingTech](https://github.com/InnovatingTech) GitHub profile. Reports are reviewed on a best-effort basis; this policy does not create a support SLA.
